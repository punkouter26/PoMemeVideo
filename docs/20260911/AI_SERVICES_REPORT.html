Tier 1 · The thirty-second read

One provider, two call sites

There is an AI provider: Azure AI Foundry, reached over the OpenAI chat-completions API at a *.cognitiveservices.azure.com endpoint. Exactly one vendor, one resource and two services — a director that writes the cue script and a vision service that labels keyframes. The three-provider matrix this codebase used to carry (AzureOpenAI | AiFoundry | BrowserLLM, behind a SwitchingDirectorService) has been removed; what stays runtime-mutable is which deployment the director targets.

Risk — the model selector is anonymous

PUT /api/config/ai-model carries .AllowAnonymous() ConfigEndpoints.cs:77 and mutates a process-wide singleton that every subsequent director call reads AiFoundryDirectorService.cs:60,69. The allow-list bounds the blast radius to names an operator configured, and the change is not persisted unless PoMemeVideo__PersistAiSettings=true — but any unauthenticated caller can switch the deployment every session runs on, for every user, until the next restart. Confirmed against the built app under ASPNETCORE_ENVIRONMENT=Staging: an unauthenticated PUT with {"aiFoundryDeployment":"gpt-4o-mini"} returned 200 {"aiFoundryDeployment":"gpt-4o-mini"}.

The legacy alias, and exactly what it covers

Only the vision service coalesces to AzureOpenAI:*. The director reads AiFoundry:Endpoint alone and throws without it.

// AiFoundryVisionService
var endpoint = Coalesce(config["AiFoundry:Endpoint"], config["AzureOpenAI:Endpoint"])
    ?? throw new InvalidOperationException(
        "AiFoundry:Endpoint not configured (legacy AzureOpenAI:Endpoint is also unset).");

// AiFoundryDirectorService
var endpoint = config["AiFoundry:Endpoint"]
    ?? throw new InvalidOperationException("AiFoundry:Endpoint not configured.");

AiFoundryVisionService.cs:43-45AiFoundryDirectorService.cs:41-42

Coalesce exists rather than ?? for a documented reason: “an unset key read through IConfiguration often arrives as an empty string rather than null (appsettings.json ships every secret as ""), which would win over the fallback” AiFoundryVisionService.cs:69-73. The /health endpoint reports which section answered, appending “via legacy AzureOpenAI:Endpoint — migrate to AiFoundry:Endpoint” when the canonical key is blank HealthEndpoint.cs:103-105. The director’s asymmetry means a vault carrying only the legacy keys yields a healthy-looking vision service and a director that throws at construction.

The semantic matcher that feeds the prompt

Candidate ranking is local — no embedding service, no vector store. SemanticMatchingService builds a TF-IDF index over each sound’s curated tags union the tokens of its display name, and scores with TensorPrimitives.CosineSimilarity SemanticMatchingService.cs:58-76. The design note records the measurement that forced it: “all 7 captions from a real run scored 0.000 against all 202 sounds… Indexing tags ∪ name tokens took the library from 41 distinct vectors to 191, and the worst tie group from 97 sounds to 11” SemanticMatchingService.cs:12-19. Curated Priority sounds get a ×1.5 boost SemanticMatchingService.cs:33; ties break on SoundId so the same few sounds cannot monopolise the library SemanticMatchingService.cs:72-74.
