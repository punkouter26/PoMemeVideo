# PoMemeVideo.E2ETests

This folder owns browser-level UI contract tests for the hosted app.

## Scope
- Validate user-facing flows and page contracts.
- Validate accessibility landmarks and critical navigation behavior.
- Avoid direct assertions on implementation internals.

## Run
- `npm test`
- `npm run test:report`

## Artifacts
Generated artifacts are written under `tests/PoMemeVideo.E2ETests/artifacts/` and are ignored by git.
